Production Enablement Gate

Checklist ก่อน Flash / Arm / Move

ต้องครบทุกข้อก่อนจึงอนุญาต motion จริง — ห้ามข้ามขั้นตอน

🟡A. อ่าน DI10 ขณะ E-stop ปล่อยและกด → ยืนยัน polarity สองสถานะ
🟡B. ปรับ active_state และตั้ง polarity_verified=true หลังมีหลักฐาน
🟡C. ให้ safety relay/KM1 ตัดกำลังหรือ enable ของ X, Y และ Z ครบ
🟡D. ตรวจ driver input voltage/current และ NMOS polarity ด้วย dummy load
🟡E. Scope PA8, PA9, PA5 และ PB0, PB1, PB2 โดยยังถอด driver/motor load
🟡F. เพิ่ม Nucleo motion backend ใน Controller (ห้ามใช้ nucleo_io.py)
🟡G. ผูก ARM/heartbeat กับ IRIV IO safety state แบบ fail-safe
🟡H. เพิ่ม limit-stop ระหว่าง pulse และทดสอบ watchdog/USB loss
🟡I. ทดสอบทีละแกน ความเร็วต่ำ/ระยะสั้น โดยมีผู้ควบคุม E-stop
🟡J. Calibrate direction, steps/mm, min/max/home และ soft limits
🟡K. ผ่าน HOME/JOG/STOP/E-STOP/power-cycle acceptance test
🟡L. จึงเปิด automatic slot/dispense sequence
🔴 Critical Safety Gap ที่ยังค้าง
KM1 ตัด 60V ของ X/Y แต่ 24V ของ Z/DM542 ยังไม่ผ่าน KM1 → E-Stop ทางกายภาพยังไม่หยุด Z ได้อย่างสมบูรณ์ → ห้ามอนุญาต production motion จนกว่าจะแก้ wiring Z
Road to Production

งานถัดไปตามลำดับ

1
DI10 Two-State Commissioning — ห้ามขยับมอเตอร์
อ่าน raw DI10 ขณะ E-stop ปล่อย + กด · ยืนยัน polarity ก่อนแก้ active_state · ห้ามเดาจากค่าเดียว
2
แก้ Hardwired Safety Gap ของ Z
ให้ช่างไฟต่อ safety relay/KM1 ให้ตัด enable/power ของ DM542 Z ด้วย · ทดสอบโดยไม่พึ่ง Pi/Nucleo
3
ออกแบบ Production Nucleo Backend
serial transaction lock · strict JSON/protocol validation · state machine: disconnected → disarmed → armed → moving → fault · heartbeat จาก fresh IRIV IO state · no auto-re-arm
4
เพิ่ม Z Home (DI6) แยกจาก Z Min (DI4)
แก้ homing model ให้ Z ใช้ Z Home sensor จริง ไม่ใช่ Z Min limit
5
Product Sensor Logic DI7–DI9 + Dispense Verification
drop parking, drop sensor, pickup sensor sequence สำหรับ dispense workflow อัตโนมัติ
6
Bench Scope Firmware Candidate — Driver Disconnected
scope PA8/PA9/PA5 และ PB0/PB1/PB2 บน NMOS Gate/Drain ก่อนต่อ driver ใด ๆ
7
Review / Commit Dirty Worktree เป็นชุดย่อย
แบ่ง: controller/HMI · IRIV IO mapping · Nucleo health link · STM32 candidate · docs · พร้อม backup ก่อนทุก commit
8
Controlled Low-Speed Motion Acceptance Test
ทีละแกน · ความเร็วต่ำ · ระยะสั้น · มีผู้ควบคุม E-stop · ผ่าน HOME/JOG/STOP/E-STOP/power-cycle ครบ
