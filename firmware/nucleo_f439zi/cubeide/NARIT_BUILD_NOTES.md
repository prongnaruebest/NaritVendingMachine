# NARIT NUCLEO firmware v3

This CubeIDE project targets the STM32 NUCLEO-F439ZI.

- USART3 on PD8/PD9 is the only runtime command channel. The on-board ST-LINK
  exposes it as a USB virtual COM port at 115200 baud.
- Ethernet and USB OTG initialization calls are intentionally disabled in
  `Core/Src/main.c`.
- STEP outputs are generated by timer output-compare interrupts:
  X = PA8/TIM1_CH1, Y = PA9/TIM1_CH2, Z = PA5/TIM2_CH1.
- DIR outputs are X = PB0, Y = PB1, Z = PB2.
- The firmware boots disarmed and stops/disarms after a 500 ms heartbeat timeout.
- Protocol v3 supports per-axis stop and concurrent X/Y/Z motion.
- Maximum accepted pulse frequency is 50,000 Hz. This is an electrical/firmware
  ceiling, not a commissioned mechanical speed.

Build with STM32CubeIDE 1.19 or its `headless-build.bat` command. Do not
regenerate code from the original `.ioc` without preserving the NARIT user code
and the intentionally disabled Ethernet/USB OTG initialization.
